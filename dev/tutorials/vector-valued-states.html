Vector-Valued ODE States (Laplace) ​

An ODE state can be a vector: when its @initialDE value is a vector, the state is a vector inside @DifferentialEquation, and x(t) returns the vector in @formulas (see Vector-Valued States). This tutorial uses that in two models on small simulated datasets: a chain of transit compartments whose length is a constant, and a latent neural ODE whose state dimension is a constant. Both are fitted with Laplace using few iterations, so the results shown are illustrative.

What You Will Learn ​

  • Declare a vector state through its initial value and write its derivative element-wise (D(x[1]) ~ ..., D(x[2:end]) ~ ...).

  • Dose into a compartment by name (CMT = "depot", or an element such as "transit[1]").

  • Change the number of compartments or the latent dimension by changing one constant.

  • Write a latent neural ODE with one line, D(x) ~ s * NN(x ./ 100.0, z_nn).

Part 1: Transit Compartments ​

The model ​

A dose enters depot, passes through NTR transit compartments, and reaches central, from which it is eliminated. transit is a vector state of length NTR because its initial value is zeros(NTR). Its first element receives from depot; elements 2 to NTR each receive from their predecessor, written as one broadcast line over the range 2:end.

julia
using NoLimits
using CairoMakie
using DataFrames
using Distributions
using Random

const NTR = 4   # number of transit compartments

model = @Model begin
    @fixedEffects begin
        ktr = RealNumber(1.5, scale = :log)
        ke = RealNumber(0.2, scale = :log)
        V = RealNumber(10.0, scale = :log)
        ω = RealNumber(0.3, scale = :log)
        σ = RealNumber(0.3, scale = :log)
    end
    @covariates begin
        t = Covariate()
    end
    @randomEffects begin
        η = RandomEffect(Normal(0.0, ω); column = :ID)
    end
    @preDifferentialEquation begin
        ktr_i = ktr * exp(η)
    end
    @DifferentialEquation begin
        D(depot) ~ -ktr_i * depot
        D(transit[1]) ~ ktr_i * (depot - transit[1])
        D(transit[2:end]) ~ ktr_i .* (transit[1:(end - 1)] .- transit[2:end])
        D(central) ~ ktr_i * transit[end] - ke * central
    end
    @initialDE begin
        depot = 0.0
        transit = zeros(NTR)
        central = 0.0
    end
    @formulas begin
        y ~ Normal(central(t) / V, σ)
    end
end

Each element of transit is given exactly once: transit[1] by the first line and transit[2] to transit[NTR] by the range 2:end. Because the range is written relative to end, the block does not depend on the value of NTR. The broadcast right-hand side is written into the derivative in place, without temporary vectors.

Data with dosing by compartment name ​

Eight subjects receive a bolus of 100 into depot at time zero. CMT names the compartment. In a model with a vector state, CMT must be a name ("depot", "central", or an element such as "transit[2]"); an integer CMT is rejected, because the position of a compartment in the state vector depends on NTR. The observations y are simulated from the model at its initial parameter values.

julia
obs_t = [0.5, 1.0, 2.0, 3.0, 4.0, 6.0, 8.0, 12.0, 24.0]
df = DataFrame(
    ID = Int[], t = Float64[], EVID = Int[], AMT = Float64[], RATE = Float64[],
    CMT = String[], y = Union{Missing, Float64}[]
)
for id in 1:8
    push!(df, (id, 0.0, 1, 100.0, 0.0, "depot", missing))
    for tt in obs_t
        push!(df, (id, tt, 0, 0.0, 0.0, "depot", 0.0))
    end
end

dm_kw = (
    primary_id = :ID, time_col = :t, evid_col = :EVID, amt_col = :AMT,
    rate_col = :RATE, cmt_col = :CMT,
)
df.y = simulate_data(DataModel(model, df; dm_kw...); rng = Random.Xoshiro(1)).y
first(df, 6)

Part 2: A Latent Neural ODE ​

Data ​

The data are concentrations of a one-compartment model with first-order absorption, computed in closed form for eight subjects with a subject-specific volume and multiplicative noise.

julia
dose, ka, ke, V = 100.0, 1.0, 0.2, 10.0
t_obs = [0.5, 1.0, 2.0, 4.0, 6.0, 8.0, 12.0, 24.0]
rng = Random.Xoshiro(3)
df_nn = DataFrame(ID = Int[], t = Float64[], y = Float64[])
for id in 1:8
    Vi = V * exp(0.2 * randn(rng))
    for tt in t_obs
        c = dose * ka / (Vi * (ka - ke)) * (exp(-ke * tt) - exp(-ka * tt))
        push!(df_nn, (id, tt, c * exp(0.1 * randn(rng))))
    end
end
first(df_nn, 6)

The model ​

The latent state x has dimension NSTATE and is measured in units of the dose. Its derivative is a feed-forward network of the state, scaled by a subject-specific factor s, minus a first-order loss kel .* x; one line describes all components. The last component, multiplied by the dose and divided by a subject-specific volume, is the predicted concentration.

julia
const NSTATE = 2   # latent state dimension

model_nn = @Model begin
    @fixedEffects begin
        tvv = RealNumber(10.0, scale = :log)
        omega_v = RealNumber(0.2, scale = :log)
        omega_s = RealNumber(0.2, scale = :log)
        sigma = RealNumber(0.1, scale = :log)
        z_nn = FFNNParameters(
            (NSTATE, 8, NSTATE); activation = :tanh,
            output_activation = :identity, function_name = :NN, calculate_se = false
        )
        kel = RealNumber(0.1, scale = :log)
    end
    @covariates begin
        t = Covariate()
    end
    @randomEffects begin
        eta_v = RandomEffect(Normal(0.0, omega_v); column = :ID)
        eta_s = RandomEffect(Normal(0.0, omega_s); column = :ID)
    end
    @preDifferentialEquation begin
        vc = tvv * exp(eta_v)
        s = exp(eta_s)
    end
    @DifferentialEquation begin
        D(x) ~ s .* NN(x, z_nn) .- kel .* x
    end
    @initialDE begin
        x = vcat(1.0, zeros(NSTATE - 1))
    end
    @formulas begin
        cp = 100.0 * x(t)[NSTATE] / vc
        y ~ Normal(cp, abs(cp) * sigma + 0.05)
    end
end

Two details keep the likelihood finite. The first component starts at 1.0 (the dose) rather than at zero: with all components at zero and the network biases at their initial value of zero, the right-hand side is zero, the state stays at zero, and the predicted concentration is zero at all times. The constant 0.05 in the standard deviation is a floor, so that a predicted concentration of zero does not give a standard deviation of zero.

To use a larger latent space, change NSTATE: the network input and output sizes, the initial value and the observed component follow from it.

Notes ​

  • Iteration counts are small. Both fits stop after a fixed, small number of iterations so that the example runs quickly; the estimates are illustrative.

  • Latent-model choices. Measuring the state in units of the dose keeps the network inputs and outputs of order one, and the loss term kel .* x gives the state a decay that the network alone has to learn otherwise. In trials for this page, the same model without these two choices did not follow the data within a few hundred iterations.

  • Element-wise or whole-vector form. D(transit) ~ ktr_i .* (vcat(depot, transit[1:(end - 1)]) .- transit) describes the same chain in one line and gives the same results; the element-wise form avoids the temporary vector created by vcat.

  • Closed-form solutions are used only for systems of scalar states, so models with a vector state are solved numerically.
